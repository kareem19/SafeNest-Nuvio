How to add it in Nuvio
  1. Copy the link above.
  2. In Nuvio, open the addons screen and choose to add an addon by URL.
  3. Paste the link and confirm. A SafeNest card now appears in the source list of each title.
  4. Tap a card to open the original Common Sense Media page.

Good to know

The label is an estimate based on Common Sense Media's age rating and descriptions (with other sources as backup). It is a guide, not a guarantee: always check what is right for your family. SafeNest is not affiliated with Common Sense Media, TMDB or IMDb.
